# DataGear（前后端分离版）软件使用说明书

> 面向最终用户与运维人员的操作手册。默认地址：前端 `http://localhost:5173`（开发）或后端 `http://localhost:50401`（生产单端口）。

---

## 一、安装与启动

### 1.1 环境要求
- JDK 8+、Node.js 20+（仅前端开发/构建需要）、MySQL 5.7/8.x。
- 数据库：创建库 `datagear`，默认账号 `root/root1020`（可在配置中修改）。

### 1.2 开发态启动
```bash
# 1) 启动后端（50401）
mvn spring-boot:run -pl datagear-webapp \
  -Dspring-boot.run.arguments="--disableLoginCheckCode=true"

# 2) 启动前端（5173，代理 /api 到 50401）
cd datagear-web-ui && npm install && npm run dev
```
浏览器访问 `http://localhost:5173`。

### 1.3 生产态启动（单端口）
```bash
mvn package -DskipFrontend=false          # 打包（前端 dist 拷入 static/）
java -jar datagear-webapp/target/datagear-6.0.0.war
```
浏览器访问 `http://localhost:50401`（后端直接托管整个 SPA）。

### 1.4 默认账号
- 用户名 `admin`，密码 `admin`（首次登录后建议立即修改）。
- 开发态已通过 `--disableLoginCheckCode=true` 关闭登录校验码；生产态默认开启。

## 二、登录与退出

1. 打开系统首页 → 未登录自动跳转登录页。
2. 输入用户名/密码（生产环境输入校验码）→ 点击登录。
3. 登录成功后进入首页，左侧为功能菜单。
4. 右上角「退出」按钮退出登录。
5. 忘记密码：登录页「忘记密码」→ 输入用户名 → 按提示在服务器校验目录创建指定文件名 → 校验通过后设置新密码。
6. 注册：登录页「注册」（若管理员未禁用注册）。

## 三、功能模块使用说明

### 3.1 数据源管理
路径：菜单「数据源」
- **新建数据源**：点击「新建数据源」→ 选择类型 → 填标题/URL/用户/密码 → 选择 JDBC 驱动（可自动检测）→ 保存。
- **URL 构建器**：编辑页 URL 输入框旁「构建器」→ 选数据库类型 → 填主机/端口/库名 → 生成并复制 JDBC URL。
- **驱动管理**：菜单「驱动管理」→ 新建驱动（驱动类名/名称）→ 保存后「上传 jar」。
- **数据源防护**：菜单「数据源防护」→ 配置 URL 匹配模式，允许/禁止特定数据源连接。
- **数据管理**：数据源列表「数据管理」→ 选数据表 → 浏览/新增/编辑/删除表数据。
- **SQL 工作台**：数据源列表「SQL 工作台」→ 编写 SQL → 执行 → 查看结果/历史。
- **数据导入/导出**：数据源列表「导入/导出」→ 按向导选表、格式（CSV/JSON/Excel/SQL）→ 执行并下载结果。

### 3.2 数据集管理
路径：菜单「数据集」
- 点击「新建数据集」→ 选择类型：
  - **SQL**：名称 + 数据源 + SQL（可「预览解析」）。
  - **JSON 值/CSV 值**：名称 + 直接粘贴文本。
  - **JSON 文件/Excel/CSV 文件**：名称 + 文件名（数据集目录）。
  - **HTTP 接口**：名称 + URL + 请求方法（GET/POST）+ 请求体。
- 行操作：编辑/授权/删除。

### 3.3 图表管理
路径：菜单「图表」
- 行操作「设计」进入图表设计器：
  - 图表名称 + 属性面板（图表类型/数据绑定/样式/交互）。
  - 右侧实时 ECharts 预览（保存后刷新）。
- 「授权」：将图表授权给用户/角色（只读权限）。
- 「删除」：删除图表。

### 3.4 看板管理
路径：菜单「看板」
- 「新建看板」：填名称 → 保存后自动进入设计器。
- 「设计」：看板画布，插入图表挂件（拖拽排序）、移除、保存。
- 「分享」：设置密码分享 / 匿名可访问密码。
- 「导入看板」：上传 zip 看板包 → 解析模板 → 导入。
- 「授权」：看板数据权限。

### 3.5 用户/角色/授权
- **角色管理**：新建/编辑/删除角色（数据管理员/数据分析员/注册用户）。
- **用户管理**：新建/编辑用户（用户名/密码/角色）、「改密码」、删除（数据迁移至目标用户）。
- **资源授权**：各资源列表页「授权」→ 选择主体（用户/角色/所有用户/匿名）→ 选择权限（只读/编辑/删除）→ 启用。

### 3.6 分析项目 / 文件源
- **分析项目**：数据资源的组织维度，新建/编辑/删除/授权。
- **文件源**：配置文件系统目录，供文件型数据集使用。

### 3.7 图表插件管理
路径：菜单「图表插件」
- 查看已安装插件（150 内置），「上传插件」安装 zip 插件包，「删除」卸载。

## 四、常见问题（FAQ）

| 问题 | 解决 |
|---|---|
| 登录提示校验码错误 | 开发态已关闭；生产态刷新校验码图片后重试 |
| 图表预览空白 | 检查数据集绑定字段标记（name/value）是否正确 |
| 数据源连接失败 | 检查 URL/端口/驱动 jar 是否已上传、防护规则是否拦截 |
| 看板分享后无法访问 | 确认分享密码已启用，访问时输入正确密码 |
| 前端页面 404/白屏 | 确认后端已启动且端口正确；深层链接需后端 SPA 回落（已配置） |

## 五、权限说明

- **数据管理员（admin）**：全部功能。
- **数据分析员**：数据源/数据集/图表/看板的读写，可被授权访问他人资源。
- **注册用户**：默认只读，需管理员授权。
- **匿名用户**：仅能访问开启了「匿名可访问」的看板（需密码）。
