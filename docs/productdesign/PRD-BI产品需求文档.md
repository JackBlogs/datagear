## 产品概述

### 产品定位

DataGear 是一款**开源免费的商业智能（BI）分析平台**，核心价值主张从「自由制作任何数据看板」升级为「**一站式数据接入、治理、建模、分析与展示平台**」。产品在保持私有化单体部署、轻量开箱即用的同时，补齐数据治理、数据存储、数据下钻、统计报表、系统管理与数据交换分享能力，覆盖「接入 → 存储 → 治理 → 建模 → 分析 → 展示 → 分享」完整数据链路。

### 产品背景与要解决的问题

| 痛点 | DataGear 的解法 |
| --- | --- |
| 数据分散在数据库、文件、接口、消息队列等，缺乏统一入口 | 统一数据源管理，支持 JDBC 数据库、Excel/CSV/JSON 文件、HTTP 接口、实时流等多类接入 |
| 数据质量参差、口径不一、缺乏治理 | 元数据管理、数据标准、数据质量、数据血缘、指标管理、数据脱敏构成数据治理体系 |
| 传统 BI 笨重、部署复杂、成本高 | 单体轻量架构，Java 8+ 即可运行，私有化掌控数据 |
| 图表类型有限、缺 GIS/三维/大屏能力 | 70+ 内置图表 + GIS 地图工具 + 三维立体图表 + 大数据可视化大屏 + 图表插件机制 |
| 分析深度不足，难以层层下钻 | 数据钻取、图表联动、跳转穿透、参数过滤构成自助交互分析体系 |
| 报表能力弱、无法满足中国式复杂报表 | 分组报表、交叉表、电子表格、填报、定时订阅推送与多格式导出 |
| 权限与数据安全难保障 | 基于角色的功能权限 + 资源/行列级数据权限 + 数据源防护 + 加密与脱敏 |
| 数据难以对外交换与分享 | 数据导入导出、数据 API 服务、看板/报表分享、订阅推送 |

### 目标用户与典型场景

| 角色 | 场景 |
| --- | --- |
| 数据分析师 | 连接数据源、建模、拖拽生成图表、搭建看板与报表、自助下钻分析 |
| 业务人员 | 查看门户首页、访问已分享看板/报表、通过交互表单与钻取自取所需数据 |
| 数据工程师 | 配置数据接入、执行数据治理、维护元数据与数据质量、开发数据交换任务 |
| 开发人员 | 自定义图表插件、扩展数据源驱动、调用数据 API、二次开发 |
| 系统/数据管理员 | 管理用户/角色/组织/数据权限、数据源防护、系统配置 |
| 企业决策层 | 大屏驾驶舱、经营报表、指标看板的集中展示与分享 |

### 产品价值

- **安全稳定**：私有化部署、数年迭代、基于角色的权限、数据默认私有、加密脱敏。
- **功能丰富**：多源接入、六类数据集、70+ 图表、GIS/三维/大屏、报表、模板化看板。
- **治理可控**：元数据、数据标准、数据质量、数据血缘、指标管理一体的轻量数据治理。
- **易于扩展**：运行时数据源驱动、自定义图表插件、开放看板 API 与数据 API。
- **自由制作**：原生 HTML 模板、可视化/源码编辑、多端响应式、联动钻取。

## 数据接入

### 功能概述

对可接入的外部数据进行统一注册、维护与访问控制，覆盖数据库、文件、HTTP 接口、实时流等多类来源，是平台的数据入口。

### 数据库接入

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| FR-DS-01 | 新建/编辑数据源 | 标题、JDBC URL、用户名、密码、模式名（Schema）、连接属性、指定驱动 |
| FR-DS-02 | 删除/复制数据源 | 级联清理关联历史；复制快速生成同构数据源 |
| FR-DS-03 | 连接校验 | 保存前测试数据库连通性 |
| FR-DS-04 | 数据源列表/分页查询 | 支持关键字、创建用户过滤 |
| FR-DS-05 | 表结构浏览 | 读取库/模式/表/列元信息（依赖 datagear-meta） |
| FR-DS-06 | 表数据查看/编辑 | 分页查询、增删改（依赖 datagear-persistence） |
| FR-DS-07 | 数据导入/导出 | CSV/Excel/JSON/SQL 格式（依赖 datagear-dataexchange） |
| FR-DS-08 | 数据源防护 | 基于 URL/用户/连接属性的防护规则 |
| FR-DS-09 | 密码加密存储 | 支持 `{noop}`/`{std}` 前缀，可配置 AES 加密 |

**业务规则**：

1. 数据源默认仅创建者可见，通过授权共享给角色/用户/全部/匿名。
2. 数据源密码默认明文（可配置开启加密），采用可配置密钥+盐。
3. 表类型可区分「数据表（可查）/实体表（可读写）」。

### 文件数据接入（Excel/CSV/JSON）

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| FR-FILE-01 | Excel 数据集 | 读取 xls/xlsx，指定 Sheet、表头行、行列表达式 |
| FR-FILE-02 | CSV 数据集 | 粘贴文本或读取文件，指定编码、分隔符、表头行 |
| FR-FILE-03 | JSON 数据集 | 粘贴 JSON 文本或读取 JSON 文件，支持 JSON 路径解析 |
| FR-FILE-04 | 目录文件数据集 | 读取目录内多文件，按文件名模式合并 |
| FR-FILE-05 | 文件源管理 | 上传/下载数据集文件、目录管理、文件源授权 |
| FR-FILE-06 | 文件数据预览 | 上传后预览字段与样例数据，自动识别类型 |

### API 与 HTTP 接口接入

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| FR-HTTP-01 | HTTP 数据集 | URI、请求头、方法、请求体、响应 JSON 路径、附加属性 |
| FR-HTTP-02 | 认证配置 | 支持 Basic/Bearer Token/自定义头等鉴权 |
| FR-HTTP-03 | 分页与翻页 | 支持分页参数、翻页取值，自动拼接多次请求 |
| FR-HTTP-04 | 响应解析 | JSON/XML 响应解析，支持 JSONPath 提取数据路径 |

### 实时与流式数据接入（规划）

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| FR-STREAM-01 | 实时数据源 | 接入 Kafka、MQTT 等消息流，支撑实时看板 |
| FR-STREAM-02 | 定时刷新 | 图表/看板按间隔自动刷新 |
| FR-STREAM-03 | WebSocket 推送 | 数据变更通过 WebSocket 推送至前端实时渲染 |

### 数据源驱动管理

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| FR-DRIVER-01 | 驱动上传/新增 | 上传 JDBC 驱动 jar 或指定驱动类 |
| FR-DRIVER-02 | 驱动列表/启停/删除 | 驱动可启用/禁用 |
| FR-DRIVER-03 | 驱动信息解析 | 驱动类、显示名、版本、兼容 URL 模板 |
| FR-DRIVER-04 | 驱动加载 | 从指定目录（`driverRootDirectory`）动态类加载 |

**扩展点**：支持 MySQL、PostgreSQL、Oracle、SQL Server、Elasticsearch、ClickHouse、OceanBase、TiDB、人大金仓、达梦、海量等；实现 `DriverEntityManager` / `PathDriverFactory` 可扩展加载策略。

### SQL 工作台

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| FR-SQLPAD-01 | SQL 编辑与执行 | 多语句执行、结果集展示 |
| FR-SQLPAD-02 | SQL 历史 | 记录执行过的 SQL，可回填复用 |
| FR-SQLPAD-03 | 结果导出 | 将查询结果导出为文件 |
| FR-SQLPAD-04 | SQL 防注入 | 按权限档位校验非法关键字 |
| FR-SQLPAD-05 | 执行提交与异步执行 | 支持提交式执行（`SqlpadExecutionSubmit`） |

### 数据源防护

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| FR-GUARD-01 | 防护规则 CRUD | 名称、URL 模式、用户模式、连接属性模式、匹配模式、优先级、启停 |
| FR-GUARD-02 | URL/属性防护 | 按 URL 模式 + 连接属性模式判定「允许/拒绝」 |
| FR-GUARD-03 | 内置漏洞防护 | 如禁用 MySQL `allowLoadLocalInfile` 等任意文件读取漏洞 |

## 数据处理与建模

### 功能概述

将数据源、文件、HTTP 接口等抽象为统一「数据集」，并提供建模能力，供图表/看板/报表消费。

### 数据集类型

| 类型 | 标识 | 说明 | 关键配置 |
| --- | --- | --- | --- |
| SQL 数据集 | `SQL` | 基于数据源执行 SQL 查询 | 数据源、SQL 语句、参数 |
| HTTP 数据集 | `HTTP` | 调用 HTTP 接口并解析响应 | URI、请求头、方法、请求体、响应 JSON 路径 |
| JSON 值数据集 | `JsonValue` | 直接粘贴 JSON 文本 | JSON 内容、数据 JSON 路径 |
| JSON 文件数据集 | `JsonFile` | 读取 JSON 文件 | 文件名、编码、数据 JSON 路径、文件源 |
| CSV 值数据集 | `CsvValue` | 直接粘贴 CSV 文本 | CSV 内容、表头行 |
| CSV 文件数据集 | `CsvFile` | 读取 CSV 文件 | 文件名、编码、表头行、文件源 |
| Excel 数据集 | `Excel` | 读取 Excel 文件 | 文件名、Sheet、表头行、行列表达式 |
| 目录文件数据集 | （文件目录） | 读取目录内多个文件 | 目录、文件名模式 |

### 数据集参数与参数化语法

- 参数类型：`string / boolean / integer / number / object`。
- 参数输入控件：`text / select / radio / checkbox / textarea / date / time / datetime`，`select` 等可携带 `inputPayload` 定义选项 JSON。
- **参数化语法（SQL/JSON/CSV 模板）**：基于 Freemarker，使用 `${参数名}` 引用参数；SQL 数据集额外提供 `${pc(参数名)}` 预编译函数，防止 SQL 注入。

### 数据建模与多维分析

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| FR-MODEL-01 | 字段定义 | 字段类型、标签、默认值、表达式（计算字段）、全名（嵌套路径）、是否数组 |

### 图表插件机制

- **形态**：一个 zip 包，至少包含 `plugin.json`、`renderer.js`、`icon.png`。
- **plugin.json 关键字段**：`id`、`nameLabel`、`icons`、`dataSignSpec`、`dataSetRange`、`version`、`order`、`categoryInfos`、`author`、`apiVersion`、`platformVersion`。
- **renderer.js**：一个 IIFE，接收 `plugin` 对象，返回图表渲染对象。
- **放置位置**：`chartPluginRootDirectory`（默认 `${DATAGEAR_HOME}/chartPlugin`）。
- 支持重写/扩展内置插件、自定义图表选项、自定义组件接入拖拽组件库。

## 关键业务流程

### 数据接入 → 治理 → 展示主流程

```
数据接入（数据库/文件/HTTP/实时流）
   → 数据存储（元数据入库 / 缓存 / 抽取物化）
   → 数据治理（元数据 / 标准 / 质量 / 血缘 / 指标 / 脱敏）
   → 建立数据集（SQL/HTTP/CSV/Excel/JSON，定义字段与参数）
   → 创建图表/报表（选插件，绑定数据集，做数据标记）
   → 组装看板/大屏（HTML 模板 + 图表部件 + 联动/钻取）
   → 分享/嵌入（密码分享、iframe、数据 API）
   → 终端展示（多端响应式、实时刷新、下钻分析）
```

### 数据集查询流程（参数化）

```
看板/图表/报表请求 → 携带参数值（DataSetQuery）
   → 数据集模板解析（Freemarker，${param} / ${pc(param)}）
   → 连接数据源执行（SQL/HTTP/文件读取）
   → 结果结构化（字段映射、类型转换、附加数据）
   → 返回 DataSetResult → 图表/报表渲染
```

### 权限校验流程

```
请求 → 登录态识别（用户/匿名）
   → 功能权限（角色/菜单）
   → 数据权限（Authorization 表：资源 × 主体 × 权限值 + 行列级过滤）
   → 数据脱敏（敏感字段按角色脱敏）
   → 业务执行
```

## 术语表

| 术语 | 含义 |
| --- | --- |
| 数据源（DtbsSource/Schema） | 注册到系统的外部数据库连接信息 |
| 数据集（DataSet） | 图表/看板/报表消费的统一数据抽象 |
| 图表部件（ChartWidget） | 绑定数据集与插件后的具体图表实例 |
| 图表插件（ChartPlugin） | 定义图表渲染逻辑与数据标记的可插拔单元 |
| 数据标记（DataSign） | 数据集字段到图表语义（名称/数值/类别）的映射 |
| 看板（Dashboard） | 基于 HTML 模板的多图表展示容器 |
| 大屏（Big Screen） | 面向大屏展示的看板形态 |
| 数据权限（Authorization） | 资源 × 主体 × 权限值 的授权 |
| 数据源防护（Guard） | 阻止恶意数据源 URL/连接属性的规则 |
| 文件源（FileSource） | 数据集文件的存储目录 |
| 项目（AnalysisProject） | 数据集/图表/看板/报表的归组单元 |
| 元数据（Metadata） | 描述数据的数据，含技术元数据与业务元数据 |
| 数据血缘（Lineage） | 数据从源头到消费端的流转与依赖关系 |
| 指标（Metric） | 统一口径的业务度量 |
| 数据脱敏（Masking） | 对敏感数据做变形处理以保护隐私 |
