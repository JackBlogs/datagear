## 2. 产品概述

### 2.1 产品定位

DataGear 是一款**开源免费的数据可视化分析平台**，核心价值主张为「**自由制作任何数据看板**」。产品采用私有化单体部署，轻量架构、开箱即用，支持接入 SQL（JDBC 数据库）、CSV、Excel、HTTP 接口、JSON 等多种异构数据源，并以「数据集 → 图表 → 看板」为核心链路，帮助用户将分散的数据快速组织为可交互、可分享、多端适配的数据看板。

### 2.2 产品背景与要解决的问题

| 痛点 | DataGear 的解法 |
| --- | --- |
| 数据分散在多个数据库/文件/接口，缺乏统一入口 | 统一的数据源管理 + 多种数据集类型 |
| 传统 BI 工具笨重、部署复杂、成本高 | 单体轻量架构，Java 8+ 即可运行，私有化掌控数据 |
| 看板样式固定，无法自由定制 | 原生 HTML 模板看板，可导入任意 HTML/JS/CSS，可视化+源码双模式 |
| 图表类型有限，无法扩展 | 70+ 内置图表 + 运行时图表插件机制 |
| 数据权限与安全难以保障 | 基于角色的权限控制、数据默认私有、SQL 防注入、敏感信息加密、日志脱敏 |
| 数据库种类繁多（含国产库） | 运行时 JDBC 驱动加载，支持 MySQL/PG/Oracle/SQLServer/ES/ClickHouse 及达梦/人大金仓/海量等 |

### 2.3 目标用户与典型场景

| 角色 | 场景 |
| --- | --- |
| 数据分析师 | 连接数据源、编写 SQL 数据集、拖拽生成图表、搭建看板 |
| 业务人员 | 查看已分享的看板、通过交互表单/联动/钻取自助分析 |
| 开发人员 | 自定义图表插件、扩展数据源驱动、二次开发系统能力 |
| 系统/数据管理员 | 管理用户/角色/权限、数据源防护、系统配置 |
| 企业决策层 | 大屏、驾驶舱、经营报表的集中展示与分享 |

### 2.4 产品价值

- **安全稳定**：私有化部署、数年迭代、基于角色的权限、数据默认私有。
- **功能丰富**：数据源 CRUD/导入导出/SQL 工作台、六类数据集、70+ 图表、模板化看板。
- **易于扩展**：运行时数据源驱动、自定义图表插件、开放看板 API。
- **自由制作**：原生 HTML 模板、可视化/源码编辑、多端响应式、图表联动与钻取。

## 3. 用户角色与权限体系

### 3.1 角色定义

| 角色 ID | 名称 | 权限说明 |
| --- | --- | --- |
| `ROLE_REGISTRY` | 注册用户 | 系统新增/注册用户自动加入的基础角色 |
| `ROLE_DATA_ADMIN` | 数据管理员 | 可添加、编辑、管理数据源、项目、数据集、图表、看板 |
| `ROLE_DATA_ANALYST` | 数据分析员 | 仅可查看数据源、项目、数据集、图表、看板，展示图表和看板 |
| `ROLE_ANONYMOUS` | 匿名用户 | 受 `disableAnonymous` 控制；可访问被分享的看板/图表 |

### 3.2 权限模型

- **功能权限**：基于 Spring Security + 用户-角色绑定（`DATAGEAR_ROLE_USER`）。
- **数据权限**：基于授权表（`DATAGEAR_AUTHORIZATION`），对**数据源、项目、数据集、图表、看板、文件源**等资源按「资源 × 主体（全部/角色/用户/匿名）× 权限值（无/读/编辑/删除）」逐条授权。
- **默认私有**：数据默认仅创建者可见，可主动分享共用。
- **权限值区间**：`[0,99]`；无权限 `[0,20)`，只读 `[20,40)`，编辑 `[40,60)`，删除 `[60,99]`；另支持「读传递」权限（20/24/28），用于授权资源所表示的子级数据。

> 二次开发提示：权限值是带间隔的（如 24、28），便于各模块扩展自定义权限档位。

## 5. 功能需求详述

> 每个功能模块按「功能概述 / 功能点 / 业务规则 / 二次开发扩展点」四段描述。功能点编号形如 `FR-XX-NN`，可作为需求追踪与验收依据。

### 5.1 数据源管理（FR-DS）

**功能概述**：对可接入的外部数据库进行统一注册、维护与访问控制。

| 编号 | 功能点 | 说明 |
| --- | --- | --- |
| FR-DS-01 | 新建/编辑数据源 | 标题、JDBC URL、用户名、密码、模式名（Schema）、连接属性、指定驱动 |
| FR-DS-02 | 删除/复制数据源 | 级联清理关联的 SQL 历史等；复制快速生成同构数据源 |
| FR-DS-03 | 连接校验 | 保存前测试数据库连通性 |
| FR-DS-04 | 数据源列表/分页查询 | 支持关键字、创建用户过滤 |
| FR-DS-05 | 表结构浏览 | 读取库/模式/表/列元信息（依赖 datagear-meta） |
| FR-DS-06 | 表数据查看/编辑 | 分页查询、增删改（依赖 datagear-persistence） |
| FR-DS-07 | 数据导入/导出 | CSV/Excel/JSON/SQL 格式（依赖 datagear-dataexchange） |
| FR-DS-08 | 数据源防护 | 基于 URL/用户/连接属性的防护规则（见 5.9） |
| FR-DS-09 | 密码加密存储 | 支持 `{noop}`/`{std}` 前缀，可配置 AES 加密 |

**业务规则**：
1. 数据源默认仅创建者可见，通过授权共享给角色/用户/全部/匿名。
2. 数据源密码默认明文（可配置开启加密），采用可配置密钥+盐。
3. 表类型可区分「数据表（可查）/实体表（可读写）」。

**扩展点**：新增数据库支持无需改代码——上传对应 JDBC 驱动即可（见 5.2）；数据源 URL 构建器脚本 `db_url_builder.js` 可自定义。

| FR-DRIVER-03 | 驱动信息解析 | 驱动类、显示名、版本、兼容 URL 模板 |
| FR-DRIVER-04 | 驱动加载 | 从指定目录（`driverRootDirectory`）动态类加载 |

**扩展点**：支持 MySQL、PostgreSQL、Oracle、SQL Server、Elasticsearch、ClickHouse、OceanBase、TiDB、人大金仓、达梦等；实现 `DriverEntityManager` / `PathDriverFactory` 可扩展加载策略。

### 5.4 数据集管理（FR-DATASET）

**功能概述**：将数据源、文件、HTTP 接口等抽象为统一的「数据集」，供图表/看板消费。数据集是系统的核心数据抽象。

#### 5.4.1 数据集类型

| 类型 | 标识 | 说明 | 关键配置 |
| --- | --- | --- | --- |
| SQL 数据集 | `SQL` | 基于数据源执行 SQL 查询 | 数据源、SQL 语句、参数 |
| HTTP 数据集 | `HTTP` | 调用 HTTP 接口并解析响应 | URI、请求头、方法、请求体、响应 JSON 路径、附加属性 |
| JSON 值数据集 | `JsonValue` | 直接粘贴 JSON 文本 | JSON 内容、数据 JSON 路径、附加属性 |
| JSON 文件数据集 | `JsonFile` | 读取 JSON 文件 | 文件名、编码、数据 JSON 路径、文件源 |
| CSV 值数据集 | `CsvValue` | 直接粘贴 CSV 文本 | CSV 内容、表头行 |
| CSV 文件数据集 | `CsvFile` | 读取 CSV 文件 | 文件名、编码、表头行、文件源 |
| Excel 数据集 | `Excel` | 读取 Excel 文件 | 文件名、Sheet、表头行、行列表达式 |
| 目录文件数据集 | （文件目录） | 读取目录内多个文件 | 目录、文件名模式 |

**业务规则**：
1. 数据集由「通用头（`DATAGEAR_DATA_SET`）+ 各类型专有表」组成，各类型专有表以 `DS_ID` 外键关联。
2. 数据集可定义**字段（field）**与**参数（param）**；字段支持类型、标签、默认值、表达式（计算字段）、全名（嵌套路径）、是否数组。
3. 数据集可标记**可变模型（mutable model）**，表示返回结构不可由静态字段描述。

#### 5.4.2 数据集参数与参数化语法

- 参数类型：`string / boolean / integer / number / object`。
- 参数输入控件：`text / select / radio / checkbox / textarea / date / time / datetime`，`select` 等可携带 `inputPayload` 定义选项 JSON。
- **参数化语法（SQL/JSON/CSV 模板）**：基于 Freemarker，使用 `${参数名}` 引用参数；SQL 数据集额外提供 `${pc(参数名)}` 预编译函数，将参数值以 PreparedStatement `?` 占位符提交，防止 SQL 注入。

**扩展点**：`DataSet` 接口 + `AbstractDataSet`/`AbstractResolvableDataSet` 抽象类，可自定义全新数据集类型；`DataSetFmkTemplateResolver` 支持自定义模板解析与输出格式（SQL/JSON/CSV/XML）。

### 5.8 扩展机制（二次开发核心）

#### 5.8.1 运行时数据源驱动

- 上传 JDBC 驱动 jar 至 `driverRootDirectory`（默认 `${DATAGEAR_HOME}/driver`），无需重启即可接入新数据库。

#### 5.8.2 图表插件

- **形态**：一个 zip 包，至少包含 `plugin.json`、`renderer.js`、`icon.png`。
- **plugin.json 关键字段**：`id`、`nameLabel`（含国际化）、`icons`、`dataSignSpec`（数据标记声明）、`dataSetRange`（可绑定的数据集数量约束）、`version`、`order`、`categoryInfos`（分类）、`author`、`apiVersion`（前端 API 版本 1.0/2.0）、`platformVersion`（最低平台版本）。
- **renderer.js**：一个 IIFE，接收 `plugin` 对象，返回图表渲染对象（通常委托 `chartFactory.chartSupport.*` 渲染器）。
- **放置位置**：`chartPluginRootDirectory`（默认 `${DATAGEAR_HOME}/chartPlugin`），内置插件位于 `builtInChartPlugins/v1`、`v2`。
- 支持**重写/扩展内置插件**、自定义图表选项。

#### 5.8.3 看板前端 API（analysisapi）

- 版本 1.0（兼容）/ 2.0（当前），位于 `static/analysisapi/*`。
- 核心对象：`window.dashboardRuntime`（`registerMap`/`registerLib`/`registerLibStore`）、`chartFactory`、`dashboardFactory`、`chartSupport`、`chartTool`、`dashboardEditor`、`dashboardBuiltinMap`。
- 依赖库目录 `analysislib`（ECharts、jQuery、GeoJSON 等），插件可注册全局依赖库。

#### 5.8.4 Java 模块化二次开发

九个 Maven 模块自底向上分层，各层提供稳定 API（详见《SDS》），二次开发可按需替换/扩展：

- 新增数据集类型 → 扩展 `datagear-analysis` 的 `DataSet` 体系。
- 新增数据导入导出格式 → 扩展 `datagear-dataexchange` 的 `*DataImport/Export`。
- 新增数据库方言 → 扩展 `datagear-persistence` 的 `Dialect`/`DialectBuilder`。
- 新增数据库元信息解析 → 扩展 `datagear-meta` 的 `DevotedDBMetaResolver`。
- 新增连接池/驱动加载策略 → 扩展 `datagear-connection`。
- 新增业务实体与服务 → 扩展 `datagear-management` 的 domain/service/mapper + `datagear.sql` DDL。

### 5.12 系统设置与国际化（FR-SYS）

- 主目录 `DATAGEAR_HOME`（驱动、图表插件、看板、数据集文件、临时目录等）。
- 系统数据库支持内置 Derby 或外置 MySQL（`datasourceDialect=mysql`）。
- 主题：`blue` / `blueDark` 两套主题；国际化 message 资源。
- 首页欢迎语、跨域（CORS）、上传大小、数据集缓存、临时目录清理、新版本检测、个人设置等可配置。

## 7. 关键业务流程

### 7.1 数据接入 → 看板展示主流程

```
数据源接入（JDBC/文件/HTTP）
   → 建立数据集（SQL/HTTP/CSV/Excel/JSON，定义字段与参数）
   → 创建图表（选图表插件，绑定数据集，做数据标记）
   → 组装看板（HTML 模板 + 图表部件 + 联动/钻取）
   → 分享/嵌入（密码分享、iframe）
   → 终端展示（多端响应式、实时刷新）
```

### 7.2 数据集查询流程（参数化）

```
看板/图表请求 → 携带参数值（DataSetQuery）
   → 数据集模板解析（Freemarker，${param} / ${pc(param)}）
   → 连接数据源执行（SQL/HTTP/文件读取）
   → 结果结构化（字段映射、类型转换、附加数据）
   → 返回 DataSetResult → 图表渲染
```

### 7.3 权限校验流程

```
请求 → 登录态识别（用户/匿名）
   → 功能权限（角色）
   → 数据权限（Authorization 表：资源 × 主体 × 权限值）
   → 数据过滤（mine/other/all）
   → 业务执行
```

## 9. 术语表

| 术语 | 含义 |
| --- | --- |
| 数据源（DtbsSource/Schema） | 注册到系统的外部数据库连接信息 |
| 数据集（DataSet） | 图表/看板消费的统一数据抽象 |
| 图表部件（ChartWidget） | 绑定数据集与插件后的具体图表实例 |
| 图表插件（ChartPlugin） | 定义图表渲染逻辑与数据标记的可插拔单元 |
| 数据标记（DataSign） | 数据集字段到图表语义（名称/数值/类别）的映射 |
| 看板（Dashboard） | 基于 HTML 模板的多图表展示容器 |
| 数据权限（Authorization） | 资源 × 主体 × 权限值 的行级授权 |
| 数据源防护（Guard） | 阻止恶意数据源 URL/连接属性的规则 |
| 文件源（FileSource） | 数据集文件的存储目录 |
| 项目（AnalysisProject） | 数据集/图表/看板的归组单元 |
