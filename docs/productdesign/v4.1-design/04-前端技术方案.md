## 2 总体架构

### 2.1 分层视图（FE-ARCH-01）

```
┌──────────────────────────── 视图层 ────────────────────────────┐
│ 老页面（jQuery + Freemarker ftl）  ↔  新模块 Vue3 SPA（datagear-web-ui） │
│  看板渲染 / SQL工作台等存量         首页/指标/问数/治理/告警/API/系统  │
├──────────────────────────── 组件层 ────────────────────────────┤
│ PrimeVue 3.34（表格/表单/弹窗） + 自研能源暗域组件（DgCard/DgStatCard/  │
│ DgIndustryTag/DgEmpty/DgSkeleton/DgWatermark…，对应 theme.css 类）    │
├──────────────────────────── 状态层 ────────────────────────────┤
│ Pinia：auth / theme / locale / analysisProject / permissions / tabs │
│       + 新增 metric / chatbi / alert / home 模块 store              │
├──────────────────────────── 服务层 ────────────────────────────┤
│ axios 实例（拦截器：会话/错误/302 处理）→ REST：既有 /api 内部接口      │
│ + /api/v1/metrics 语义层 + /ai/chat（SSE）+ /alert /scheduler        │
├──────────────────────────── 图表层 ────────────────────────────┤
│ ECharts 5.6（本地 vendor / 按需 echarts.common）+ 能源暗域主题对象      │
│ + 图表插件 zip 机制（plugin.json + renderer.js，运行时加载）           │
├──────────────────────────── 编辑器 ────────────────────────────┤
│ CodeMirror 5.64（SQL/DSL/Freemarker 模板高亮）                       │
└─────────────────────────────────────────────────────────────────┘
```

| 编号 | 条款 |
| --- | --- |
| FE-ARCH-02 | 新老页面边界：以 URL 路由前缀划分——`/ui/*` 走 SPA（history fallback 到 `index.html`），其余走 Freemarker；登入态共享同一 Session Cookie |
| FE-ARCH-03 | 老页面不重写：看板渲染内核（`dashboardFactory.js` / `chartFactory.js`）继续服役；新设计器产出的看板 JSON 须兼容现有看板渲染运行时 |
| FE-ARCH-04 | 服务层统一封装 `src/api/`：与后端 Controller 一一对应，全量 TS 类型；语义层新增 `api/metric.ts`、AI 新增 `api/chatbi.ts`（SSE 流式） |
| FE-ARCH-05 | 可选模块装配：`datagear-ai` 未部署时，前端按后端能力位（capabilities 接口）隐藏问数入口与相关路由（NFR-AI-02），不得报 404 |

## 3 新模块前端落地方案

### 3.1 综合首页（FE-MOD-01）

| 项 | 方案 |
| --- | --- |
| 组件库 | 首页组件库六件（指标卡 / 看板卡 / 快捷入口 / 待办卡 / 消息卡 / 图表预览，FR-HOME-13~18）实现为 `views/home/widgets/` 下独立组件，统一 `HomeWidget` 协议（props: 配置 JSON；emits: 跳转 / 刷新） |
| 个性化布局 | 栅格布局用 sortablejs 拖拽排序 + 显隐配置，布局 JSON 存用户偏好（FR-HOME-19~22 布局管理）；「恢复默认」二次确认 |
| 指标卡区 | 横滑容器 + `useMetricCard` composable 拉取关注指标（FR-SEM-07）；数值滚动沿用原型 `countUp` 900ms 缓出算法 |
| 性能 | 各 widget 独立懒加载 + 骨架屏；首屏先渲染 KPI 区（PRD 体验目标） |

### 3.2 指标中心（FE-MOD-02）

| 项 | 方案 |
| --- | --- |
| 目录树 | PrimeVue Tree 定制为主题样式；主题域 / 部门两级 + 搜索过滤（FR-SEM-03） |
| 列表与详情 | DataTable 懒加载（POC ③ 已验证）；详情用 Drawer 抽屉 + Tabs（概览 / 口径 / 血缘 / 版本 / 认证 / 评论，PRD 5.3 页面2） |
| 血缘图 | ECharts `graph` 类型实现指标←数据集←数据源正向与指标→图表 / 报表 / 看板 / 告警反向血缘（FR-SEM-09）；节点按实体类型着色，布局 `force`，支持缩放平移 |
| 定义向导 | 五步 Stepper（选择数据集 → 维度度量 → 属性 → 预览 → 发布），每步校验可返回（UC-001）；预览调用指标查询引擎编译的参数化 SQL |
| 认证与版本 | 认证操作仅管理员可见（permissions store 控制）；版本历史 Diff 视图用 mono 字体双栏对照 |

### 3.3 智能问数 ChatBI（FE-MOD-03）

| 项 | 方案 |
| --- | --- |
| 对话流 | 自研消息流组件（虚拟滚动支撑长历史）；用户 / 系统气泡对齐原型 TP-PAGE-04 |
| 流式渲染 | SSE（`EventSource` 或 fetch + ReadableStream）接 `/ai/chat`：事件序列为 `dsl → text(delta) → chart(option) → table(data) → done`；前端按事件分阶段渲染，总耗时监控对齐 ≤5s（NFR-PERF-07）；支持「停止生成」（AbortController） |
| DSL 透明化面板 | 折叠面板展示指标 / 维度 / 筛选 / 时间窗 / SQL（FR-AI-03）；SQL 用 CodeMirror 只读高亮；「一键转图表」「复制 SQL」直接复用图表组件与剪贴板 API |
| 澄清与联想 | 澄清选项渲染为可点击按钮组（US-009）；输入联想来自术语库 + golden queries 检索接口 |
| 上下文 | store 维护会话上下文（指标 / 时间窗），顶部上下文条可清除；≥5 轮对齐 UC-002 验收 |
| 降级 | 准确率退路（NFR-AI-01：<80% 降级检索式问答）前端形态 = 同一输入框 + 检索结果列表 + 引导式取数卡片，组件预留 `mode: 'gen' \| 'search'` |

### 3.4 看板设计器（FE-MOD-04）

| 项 | 方案 |
| --- | --- |
| 拖拽 | 一期用 sortablejs（已在依赖内）做组件库 → 画布拖放与画布内排序；网格吸附：指针坐标 ÷ 网格步长取整 + 对齐线；若自由画布吸附复杂度超标，降级为槽位式布局（行 / 列容器）分两期交付（对齐 P2「真拖拽」8~12 人周估算） |
| 画布 | 网格背景可开关；组件 8 向手柄缩放；多选（框选 / ⇧）/ 编组 / 置顶置底；右键菜单自研 ContextMenu |
| 属性面板 | 数据 / 样式 / 交互三 Tab；数据 Tab 字段拖拽（行 / 列 / 数值 + 六种聚合下拉）绑定数据集或指标（FR-SEM-06） |
| 联动 / 钻取 | 联动关系存看板 JSON `linkages[]`，画布连线用 SVG overlay 可视化；钻取层级存 `drillPath[]`，运行时面包屑上卷（FR-DRILL/FR-LINK） |
| 双模式 | 可视化 / 源码（CodeMirror）双向同步：以看板 JSON 为中间态，源码编辑即编辑 JSON / HTML 模板，切回时 schema 校验（FR-VIZ 双模式） |
| 兼容底线 | 设计器产出必须能被现有 `dashboardFactory.js` 渲染（FE-ARCH-03）；新增能力（指标卡组件）以图表插件形式注入 |
| 撤销重做 | 命令栈（command pattern）快照 diff，⌘Z / ⇧⌘Z；自动保存草稿（FR-COLLAB-01 前置） |

### 3.5 数据大屏（FE-MOD-05）

| 项 | 方案 |
| --- | --- |
| 适配 | 1920×1080 固定画布 + `transform: scale()` 等比缩放（监听容器 resize 计算缩放比），支持 4K / 拼接屏（PRD 6.2） |
| 轮播与刷新 | 多页轮播定时器（切换 ≤500ms）；数据刷新 5s~5min 可配（`setInterval` + 页面可见性检测，隐藏时暂停） |
| 实时通道 | WebSocket 推送通道预留（FR-RT-02），一期轮询实现，接口抽象 `RealTimeSource` 便于替换 |
| 告警滚动 | CSS  marquee 替代实现（transform 动画），每条停留 ≥3s，点击暂停弹详情（DS-SCREEN-05） |
| 无壳 | 路由声明 `meta: { shell: false }`，对齐原型 `data-no-shell`（IX-NAV-09） |

### 3.6 移动端 H5（FE-MOD-06）

| 项 | 方案 |
| --- | --- |
| 形态 | 同一 SPA 的移动端路由子集 + 响应式：viewport `width=device-width, initial-scale=1`；375 基宽单列流式；底部五 Tab 布局组件（首页 / 看板 / 问数 / 消息 / 我的，PRD 6.5） |
| 手势 | 引入轻量手势库（如 hammerjs 或自研 pointer 封装）：点按 / 双指缩放 / 滑动 / 长按 / 下拉刷新 / 上拉加载（IX-MOB-01 对照表） |
| 图表适配 | ECharts 移动端配置：tooltip 改 `triggerOn: 'click'`、axisPointer 十字跟随、roam 开启缩放 |
| 离线缓存 | 常用看板数据 + 静态资源走 Service Worker / localStorage 缓存，弱网展示缓存 + 「数据更新于 XX」横幅（PRD 6.5） |
| 推送深链 | 分享 / 推送链接带资源 ID 与参数，路由解析直达看板详情（深链，旅程 1 断点 1） |
| 轻应用 | 微信 / 企微 / 钉钉免登：OAuth 回调换取会话，前端仅处理跳转与回跳 |
