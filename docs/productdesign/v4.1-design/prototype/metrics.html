原油产量 M-OIL-001 石油 已认证 v1.2
采油厂井口产出原油经计量的商品量，不含自用油与损耗。
指标定义（语义层模型）
度量
SUM(商品油量) — ODS_采油日报表.fact_oil_daily.commercial_qty
维度
采油厂 / 区块 / 油藏类型 / 井别 / 日期
过滤条件
井状态 ∈ {生产井} 且 计量方式 ≠ 估算
统计周期
日 / 月（自然月累计）
负责人
王建国（勘探开发部）· 治理委员：张总工
权限
行级权限继承 单井级敏感
指标查询引擎 · 编译 SQL 预览
-- 由指标语义模型编译生成（Freemarker 参数化，防注入预编译） SELECT t.plant_name AS 采油厂, SUM(t.commercial_qty) AS 原油产量_吨 FROM ods_fact_oil_daily t WHERE t.dt BETWEEN ${pc(month_start)} AND ${pc(month_end)} AND t.well_status = ${pc('生产井')} AND t.meter_type <> '估算' /* 行级权限自动注入 */ AND t.org_id IN (${pc(user_orgs)}) GROUP BY t.plant_name ORDER BY 原油产量_吨 DESC;
