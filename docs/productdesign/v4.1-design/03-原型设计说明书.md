## 3 原型使用说明

| 编号 | 项 | 说明 |
| --- | --- | --- |
| TP-RUN-01 | 启动 | 在 `prototype/` 目录执行 `npm run dev -- --port 7100`（零依赖静态服务器 `scripts/dev-server.js`，支持 `--port/--host` 透传，默认 7100）；浏览器访问 `http://localhost:7100/` |
| TP-RUN-02 | 壳机制 | 壳内页面以 `<body data-page="...">` 声明身份，`shell.js` 自动注入侧栏 + 顶栏并把 `#page-content` 移入主区；无壳页（login / screen / mobile）声明 `data-no-shell` |
| TP-RUN-03 | 页面跳转 | 原型内跳转均为真实 `<a href>` / `location.href`：侧栏导航、首页各卡片、顶栏搜索（→问数页）、模板卡（→看板 / 大屏）、待办（→告警页）均可点击串联 |
| TP-RUN-04 | 演示角色 | 全程以「李明 · 数据分析师 · 华北油田」视角演示（侧栏底部用户卡）；告警数字、待办、收藏均按该角色虚构 |
| TP-RUN-05 | 演示动线 | 推荐动线：login → index（门户总览）→ metrics（定义指标）→ designer（组装看板）→ dashboards（发布分享）→ alert（配告警）→ screen（大屏展示）→ chatbi（业务问数）→ api（对外嵌入）→ mobile（随身消费） |
| TP-RUN-06 | 数据约定 | 所有数字为 `DG.series()` 伪随机 + 固定基准值生成；刷新页面数值会微波动，KPI 主值以第 6 章数据字典为准 |

## 4 逐页原型说明

> 每页含：页面目标 / 布局分区（ASCII 示意）/ 关键组件 / 演示数据 / 主要交互与状态 / PRD 映射。组件视觉与交互七态分别见 01 文档第 6 章、02 文档第 5 章。

### 4.1 综合首页 `index.html`（TP-PAGE-01）

- **页面目标**：一屏聚合「生产态势 + 个人工作入口」，兑现 FR-HOME 数据门户与 FR-SEM-07 指标关注。
- **布局分区**：

```
┌────────────────────────── 壳：侧栏 232 + 顶栏 56 ──────────────────────────┐
│ 欢迎横幅（问候 + 数据更新时间 ｜ 右侧 AI 问数胶囊入口）                        │
│ KPI 统计卡 ×4（石油/天然气/化工/煤矿，行业光晕）                              │
│ ┌─ 主栏 1fr ────────────────────┬─ 侧栏 340px ─────────────┐                │
│ │ 生产运营趋势卡（分段器+双轴图）  │ 待办与消息（3 条告警标记）  │                │
│ │ 行业看板模板库（4 模板卡）      │ 我的收藏                  │                │
│ │ 最近访问（4 宫格）             │ 数据资产概览（环形图）      │                │
│ └──────────────────────────────┴─────────────────────────┘                │
```

- **关键组件**：`.welcome` 横幅、`.quick-ask` 问数胶囊、`.stat-card`×4（`--sc-glow` 行业光晕 + `data-count` 数字滚动）、趋势卡（分段器 + 双轴线柱图）、`.tpl-card`×4 行业模板、`.fav-item` 最近访问、`.todo-item` 待办、环形图 `assetDonut`。
- **演示数据**：原油产量 12.86 万吨（▲2.4% 日环比 / ▲5.1% 同比）、天然气 4.32 亿方、化工品 3.15 万吨、原煤 28.4 万吨；资产：数据源 23 / 数据集 148 / 指标 86 / 看板 64 / 报表 41。
- **交互与状态**：分段器切换 Toast 提示；模板卡 / 最近访问 / 待办均可点击跳转；空态与骨架规范见 02 文档 IX-FB-02/03。
- **PRD 映射**：FR-HOME-01~06（门户工作台）、FR-HOME-13~18（首页组件库）、FR-HOME-25（行业模板一键套用）、FR-SEM-07；PRD 5.3 页面1。

### 4.2 登录 `login.html`（TP-PAGE-02）

- **目标**：统一认证 + 品牌第一印象；无壳整页。
- **布局**：深底 `--bg-0` + 三团氛围光晕；左侧品牌区（渐变 Logo + 「能源暗域」Slogan + 三大卖点列表），右侧玻璃登录卡（账密 + 验证码 + 「记住我」+ 登录主按钮全宽 + SSO / 扫码次入口）。
- **关键组件**：品牌 Logo（DS-BRAND-01）、`.input` 带聚焦光环、`.btn.primary lg`、错误提示条（`--danger-soft` 底）。
- **演示数据**：预填演示账号 `liming / demo@2026`；登录失败演示「密码错误，剩余尝试 4 次」。
- **交互**：登录成功跳 `index.html`；连续失败 5 次锁 10 分钟（FR-AUTH-14 登录限流）；Tab 顺序：账号 → 密码 → 验证码 → 登录。
- **PRD 映射**：6.1 入口矩阵 Web 端认证；FR-AUTH-14~17；NFR-SEC-05。

### 4.3 指标中心 `metrics.html`（TP-PAGE-03）

- **目标**：指标唯一事实源的管理与消费入口（10.3 最高优先级模块）。
- **布局**：

```
┌ 目录树 240px ─┬─ 操作栏（新建/搜索/筛选/视图） ─────────────┐
│ 石油 / 天然气  │ 指标表：名称·类型·认证·负责人·热度·操作        │
│ 化工 / 煤矿   │ （卡片视图：指标名+当前值+迷你趋势+口径摘要）    │
└──────────────┴──────────────────────────────────────────┘
        右侧抽屉 460px：概览｜口径定义｜血缘｜版本历史｜认证记录｜评论
```

- **关键组件**：目录树（行业 `.ind` 标记）、`.tbl` 指标表、认证盾标 `.tag.ok`、类型标签（原子 `.tag.info` / 派生 `.tag chem`）、详情 `.drawer` + `.tabs`、五步定义向导 `.modal`（选择数据集→维度度量→属性→预览→发布）、血缘关系图（ECharts graph）。
- **演示数据**：指标 86 个；标杆指标「原油产量」（原子、已认证、负责人李明、热度 412）、「吨油完全成本」（派生 = 完全成本 ÷ 商品量）；血缘演示 `油井日数据→ODS_采油日报表→原油产量→生产日报看板/经营大屏/告警规则`。
- **交互**：树节点过滤列表；行 hover 出操作；认证二次确认；向导每步可返回（02 文档 IX-PAGE-02）。
- **PRD 映射**：FR-SEM-01~09；US-001/002/016；UC-001；PRD 5.3 页面2。

### 4.4 智能问数 `chatbi.html`（TP-PAGE-04）

- **目标**：业务零 SQL 取数；三段式回答 + 取数逻辑透明化，建立信任。
- **布局**：左栏「我的问数」历史（按今日 / 本周 / 更早分组）；主区对话流 + 顶部上下文条 + 底部固定输入框（`+` 附件 / 联想 / 发送）。
- **关键组件**：消息气泡（用户右 `--brand-soft` / 系统左玻璃卡）、回答三段式（图表 + `.tbl` 数据表 + 结论）、「查看取数逻辑」折叠区（指标 / 维度 / 筛选 / 时间窗 / SQL，mono 字体）、澄清选项按钮组、推荐问题 chips、反馈按钮（有用 / 无用）、「转图表 / 添加到看板 / 分享」。
- **演示数据**：预置问「上月各采油厂原油产量的同比变化？」→ 答：柱图 + 数据表 +「华北采油一厂同比 +6.2% 居首…」；取数逻辑：指标=原油产量，维度=采油厂，时间=2026-08，筛选=业务域=石油。
- **交互**：流式渲染（骨架→逐字结论→图表）；歧义澄清可点击；追问保上下文 ≥5 轮；越权问题演示拒绝文案（UC-002 异常 5b）。
- **PRD 映射**：FR-AI-01/02/03/04/08/09；UC-002；US-008/009；NFR-AI-01~04；PRD 5.3 页面3。

### 4.5 看板列表 `dashboards.html`（TP-PAGE-05）

- **目标**：看板资产检索、消费与分发的入口。
- **布局**：页头（标题 + 新建看板 / 套用模板）+ 工具行（搜索 / 行业筛选 / 排序分段器 / 视图切换）+ 卡片流（缩略图 + 名称 + 行业标记 + 更新时间 + 热度 + 星标）。
- **关键组件**：看板卡（行业色缩略图）、右键菜单（编辑 / 分享 / 复制 / 删除 / 导出）、分享弹窗三 Tab（链接 / 密码 / 签名 Token 嵌入）、空态双任务入口（新建 + 模板）。
- **演示数据**：看板 64 个；标杆「华北油田生产日报」（石油橙、2 小时前、热度 1.2k）、「西气东输管网监控」。
- **交互**：排序切换即时重排；删除二次确认（提示订阅与嵌入将失效）；星标即收藏并同步首页。
- **PRD 映射**：FR-VIZ-01~11（管理面）、FR-DISP-01~10；FR-EXCH-08~10；FR-HOME-25；US-022（版本入口）。

### 4.6 看板设计器 `designer.html`（TP-PAGE-06）

- **目标**：拖拽组装看板并绑定语义层指标，验证「指标一次定义多处消费」。
- **布局**：

```
┌ 工具栏：名称｜撤销重做｜缩放｜设备切换｜源码｜保存·预览·发布 ┐
├ 组件库 260px ├────────── 画布（网格+吸附） ──────────┤ 属性面板 300px ┤
│ 图表/表格/指标卡/│ 占位符 + 选中手柄 + 联动连线          │ 数据｜样式｜交互 │
│ 文本/地图/装饰   │                                      │               │
```

- **关键组件**：组件库 `.tabs`、画布网格与 8 向手柄、属性三 Tab、字段拖拽区（行 / 列 / 数值 + 聚合下拉）、联动连线可视化、钻取面包屑、筛选器控件（日期 / 下拉 / 滑块）。

## 7 保真度边界声明

| 编号 | 边界 | 说明 |
| --- | --- | --- |
| TP-LIMIT-01 | 数据虚构 | 全部业务数据为演示虚构（第 6 章字典）；任何数值不构成真实业务结论 |
| TP-LIMIT-02 | 无真实后端 | 无登录校验、无数据库、无 API 调用；表单提交、保存、删除等仅 Toast 模拟反馈 |
| TP-LIMIT-03 | 图表渲染 | 图表为本地 `echarts.min.js` 真实渲染，但数据源是 `DG.series()` 伪随机序列；刷新页面趋势数值会波动（KPI 主值以字典为准） |
| TP-LIMIT-04 | 拖拽仅视觉示意 | 设计器拖拽、吸附、连线为静态 / 半交互示意，不代表最终工程实现手感；工程方案见 04 文档 FE-MOD-04 |
| TP-LIMIT-05 | 问数为脚本化演示 | ChatBI 对话为预置脚本（固定问答对），无真实 LLM 调用；流式效果为逐字定时器模拟 |
| TP-LIMIT-06 | 大屏缩放 | 大屏按 1920×1080 设计，原型以 scale 等比缩放演示；拼接屏 / 4K 实拍不在原型范围 |
| TP-LIMIT-07 | 移动端为框内演示 | `mobile.html` 在桌面浏览器内以手机框演示 H5，未做真机手势事件全套实现 |
| TP-LIMIT-08 | 权限与脱敏 | 行列权限、脱敏、审计在原型中为界面展示，不具真实拦截能力 |
| TP-LIMIT-09 | 未覆盖页面 | SQL 工作台、驱动管理详情、报表设计器全功能、填报、MCP 配置页未出原型（按 TP-ARCH-03 的 Phase 归属后置） |
| TP-LIMIT-10 | 验收口径 | 原型验收以「页面结构 / 视觉 token / 交互模式 / PRD 映射完整性」为准，不以数据正确性与功能闭环为准 |
