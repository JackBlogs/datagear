## 1 设计原则

| 编号 | 原则 | 可操作定义 | 验收方式 |
| --- | --- | --- | --- |
| DS-PRIN-01 | 暗色矿物基底 | 全部页面以 `--bg-0~--bg-4` 五级暗色矿物层叠构建纵深，禁止纯白大底；页面级底色用 `--bg-1 #0A0E17` | 走查任意页面不存在 `#FFF` 系背景 |
| DS-PRIN-02 | 光晕氛围 | 全局仅一层氛围光晕（`body::before` 三团径向渐变：右上石油橙、左下天然气青、底部化工紫），局部光晕仅用于统计卡 `--sc-glow`、Logo、激活导航；禁止大面积高饱和发光 | 单屏内自发光元素 ≤3 处 |
| DS-PRIN-03 | 玻璃拟态层级 | 卡片/浮层统一 `--bg-glass` 系 + `backdrop-filter: blur()` + 1px `--line-1` 描边；层级越高玻璃越亮（`.035→.06→.09`） | 卡片与页面底可肉眼区分层级 |
| DS-PRIN-04 | 行业语义色贯穿 | 石油橙 `#FF8A3D` / 天然气青 `#22D3EE` / 化工紫 `#A78BFA` / 煤矿金 `#E8B33C` 四色在指标、看板、大屏、告警、模板库中语义恒定，不得互换 | 同一行业对象在任意页面同色 |
| DS-PRIN-05 | 数据优先、信息密度 | 数字用 `--font-num` 等宽展示；卡片内边距 16/18px、网格间距 14px，优先保证一屏信息密度，装饰元素不得挤占数据区 | 首屏 KPI ≥4 个完整可读 |

## 6 组件规范

> 每个组件给出：结构类名（= theme.css 选择器）、尺寸、状态、用法约束。交互七态细则见《02 交互设计规范》第 5 章。

### 6.1 按钮 `.btn`（DS-COMP-01）

| 项 | 规范 |
| --- | --- |
| 结构 | `.btn` + 变体：`.primary` / `.ghost` / `.danger`；尺寸：默认 / `.sm` / `.lg`；内嵌 SVG 图标 `15px` |
| 尺寸 | 默认 `padding:7px 16px; font-size:13px; r-m`；`.sm` `4px 10px / 12px / 8px`；`.lg` `10px 22px / 14px` |
| 五态 | 默认（玻璃底 + `--line-2`）→ 悬停（`--bg-glass-3` + `--line-3`）→ 激活（`transform:scale(.97)`）→ 禁用（`opacity:.45; not-allowed`）→ 加载（禁用 + 旋转图标，见 02 文档 IX-FB-02） |
| 约束 | 主按钮 `.primary` 用 `--brand-grad` + 深棕文字 `#241105`；每屏主按钮 ≤1 个；危险操作用 `.danger` 且必须配二次确认（IX-FB-05） |

### 6.2 卡片 `.card` 与统计卡 `.stat-card`（DS-COMP-02 / 03）

| 项 | 规范 |
| --- | --- |
| 卡片结构 | `.card`（玻璃底 + `--line-1` + `--r-l` + `blur(10px)` + `padding:16px 18px`）；`.card.hover` 悬停上浮 `-2px` + `--shadow-2`；标题 `.card-title` 带 `--brand-grad` 3px 竖条 `.bar` 与右侧 `.more` |
| 统计卡结构 | `.stat-card` = `.s-label`（行业标记 + 指标名 + 时间口径）+ `.s-value`（30px 数字 + `.unit` 单位）+ `.s-foot`（`.trend.up/.down/.flat` 同环比） |
| 统计卡光晕 | 右上角 `::after` 圆形光晕，颜色由行内 `--sc-glow` 按行业色指定（如 `rgba(34,211,238,.13)`） |
| 约束 | 同环比固定顺序「日环比 → 同比」；上涨 `--ok` ▲、下跌 `--danger` ▼、持平 `--tx-3` —；点击统计卡应下钻（PRD 5.3 页面1） |
