## 1 交互设计原则

> 对齐 PRD 5.1 六条原则，并落地为可操作、可验收条款。

| 编号 | 原则（PRD 5.1） | 可操作条款 | 验收口径 |
| --- | --- | --- | --- |
| IX-PRIN-01 | 一致性 | 相同功能跨页面交互一致：保存一律主按钮 + ⌘S；删除一律 `.btn.danger` + 二次确认；时间粒度切换一律分段器 `.seg`；反馈一律走 `DG.toast` 规范位 | 走查 15 个原型页面同构操作无第二种模式 |
| IX-PRIN-02 | 即时反馈 | 用户操作后 ≤200ms 给出视觉反馈（悬停 / 按压 / loading 起始）；加载状态必须明确（骨架屏 / 按钮 loading / 行占位） | 交互响应 ≤200ms，对齐 PRD 6.4 PC 端口径 |
| IX-PRIN-03 | 容错性 | 危险操作（删除 / 发布 / 吊销 / 停用）必须二次确认并说明后果；支持撤销的场景（看板编辑）提供 ⌘Z；错误提示须「原因 + 建议 + 重试」三要素 | 危险操作 100% 有确认；错误提示无技术堆栈外露 |
| IX-PRIN-04 | 渐进式 | 复杂功能分步引导（指标向导 5 步、告警配置 3 步、数据源向导 3 步）；首次登录按角色展示新手引导，可跳过、可在帮助中重开（FR-HOME-23）；老手可跳过 | 引导可跳过率与重开入口走查通过 |
| IX-PRIN-05 | 可访问性 | 新建 Vue3 页面支持键盘操作、焦点可见、对比度 WCAG AA（NFR-AVAIL-08）；旧 jQuery 页面明示豁免并列入豁免清单随版本维护 | 键盘走查 + 对比度检测工具 + 屏幕阅读器抽测 |
| IX-PRIN-06 | 移动端优先（限消费场景） | 查看 / 批注 / 审批 / 问数 / 订阅接收类场景移动端优先设计；设计类（看板 / 报表 / 大屏设计器）桌面优先，移动端不提供 | 移动端功能边界与 PRD 6.3 功能对比表一致 |

## 2 全局导航交互

| 编号 | 项 | 交互规范 |
| --- | --- | --- |
| IX-NAV-01 | 侧栏结构 | 五分组固定顺序：概览（综合首页 / 指标中心 / 智能问数）→ 数据资产（数据源 / 数据集 / 数据治理）→ 分析展示（看板 / 看板设计器 / 数据大屏 / 统计报表）→ 运营协同（告警与订阅 / 开放与嵌入 / 移动端）→ 平台（系统管理）；与 `shell.js NAV` 及 PRD 9.2 信息架构对齐 |
| IX-NAV-02 | 当前项 | 当前页导航项高亮：`--brand-soft` 渐变底 + `--brand` 字 + 左侧 3px `--brand-grad` 指示条（带光晕）；分组标题 11px 字距 2px |
| IX-NAV-03 | 折叠态 | 底部折叠按钮切换 232px ↔ 64px；折叠后仅显示图标（居中），隐藏分组标题与徽章，悬停图标弹 tooltip 显示名称；折叠动画 `.18s`，结束后派发 resize 使图表重排 |
| IX-NAV-04 | 导航徽章 | 新功能标「新」、AI 能力标「AI」、待处理数标数字（如告警与订阅「3」）；徽章用 `.nav-badge`，计数用 `--font-num` |
| IX-NAV-05 | 全局搜索 | 顶栏胶囊搜索框（max-width 460px），⌘K / Ctrl+K 唤起；输入即时联想，跨资源搜索指标 / 看板 / 数据集（PRD 5.2）；无结果时给「换个关键词」与「向 AI 提问」两个出口，后者跳转智能问数并携带关键词 |
| IX-NAV-06 | 面包屑 | 顶栏左侧面包屑取自 `PAGE_META.crumbs`，末级加粗 `--tx-1`，分隔符 `/` 用 `--tx-4`；二级页面（如看板详情）面包屑可点击返回列表 |
| IX-NAV-07 | 顶栏动作区 | 右起：环境标签（如「生产环境 · 信创适配」`.env-tag`）→ 告警通知（红点 `.dot` 表示未读，点击开消息抽屉）→ 帮助与新手引导（重开 FR-HOME-23 引导）；用户区固定侧栏底部（头像 + 姓名 + 角色，点击开账户菜单） |
| IX-NAV-08 | 多入口跳转 | 同一资源必须多入口可达：统计卡 → 指标详情；模板卡 → 看板 / 大屏；待办告警 → 告警历史与归因；最近访问 → 对应资源页；跳转后目标页须带上下文（如预选中的指标） |
| IX-NAV-09 | 无壳页面边界 | 登录页、数据大屏、移动端 H5 三类 `data-no-shell` 页面不挂侧栏 / 顶栏；从无壳页返回壳内页须经显式「退出 / 返回」入口，禁止浏览器回退裸奔 |
| IX-NAV-10 | 新建入口 | 「新建」主操作在各列表页页头（`.page-actions`）以 `.btn.primary` 呈现；首页快捷入口宫格直达新建数据源 / 数据集 / 图表 / 看板 / 报表 / 大屏（PRD 5.3 页面1） |

## 3 全局反馈规范

| 编号 | 反馈类型 | 规范（对齐 PRD 5.2） |
| --- | --- | --- |
| IX-FB-01 | Toast | 顶部居中（top:70px）；成功 `--ok` 语义 3 秒自动消失；重要操作（发布 / 认证）Toast 内可带「查看」链接停留至手动关闭；同屏 Toast 堆叠间距 8px，最多 3 条，先进先出 |
| IX-FB-02 | 加载 | 按钮点击即 loading（禁用 + 旋转图标）；页面加载用骨架屏 `.skeleton`；表格数据加载用行占位；>10 秒提示「加载较慢，请耐心等待」并提供取消按钮（PRD 5.4） |
| IX-FB-03 | 空态 | 无数据 = 插图 + 说明 + 操作按钮；核心空态页（看板 / 指标 / 数据集列表为空）必须给出任务化教学入口（FR-HOME-24），如「还没有看板 → 新建看板 / 套用行业模板」；搜索无结果提示「没有找到相关结果，试试其他关键词」 |
| IX-FB-04 | 错误 | 错误图标 + 原因 + 解决建议 + 重试按钮；权限不足只提示「您暂无权限」不暴露数据；技术错误不暴露堆栈（PRD 5.4）；查询超时建议「重试 / 缩小时间范围」（UC-001 异常流程） |
| IX-FB-05 | 危险二次确认 | 删除 / 发布 / 吊销 / 停用弹确认框，说明后果（如「删除后关联数据集将不可用」），按钮文案「确认删除 / 取消」，确认键用 `.btn.danger`（PRD 5.2） |
| IX-FB-06 | 表单校验 | 必填标 `*`；失焦即校验；错误红字在字段正下方；提交时全量校验并滚动定位到首个错误项 |
| IX-FB-07 | 撤销 | 看板设计器 / 数据集编辑支持 ⌘Z 撤销、⇧⌘Z 重做；列表删除类操作在 Toast 内提供「撤销」窗口（5 秒）的场景：删除收藏、移除关注 |
| IX-FB-08 | 成功 | 保存成功绿色 Toast；发布成功弹窗给「查看 / 继续编辑」双出口；复制类（复制链接）即时 Toast「已复制到剪贴板」 |
| IX-FB-09 | 进度 | 文件导入 / 项目导入导出 / 备份恢复用 `.progress` 进度条 + 百分比数字（`--font-num`）；长任务给可最小化的进度卡片 |

## 4 核心页面交互细则

> 4.1~4.5 对齐 PRD 5.3 五个核心页面并细化到控件级；4.6~4.10 为扩展页。页面清单与《03 原型设计说明书》第 2 章信息架构一一对应。

### 4.1 综合首页（IX-PAGE-01）

| 区域 | 交互细则 |
| --- | --- |
| 欢迎横幅 | 问候语随时间段变化（早 / 午 / 晚）；副标展示数据更新时间与调度准时率；整区静态无交互 |
| AI 问数入口 | 胶囊框悬停发光（`--shadow-glow-brand`）；点击整框跳 `chatbi.html` 并携带占位问题；「问 AI」按钮悬停提亮 |
| 指标卡横滑区 | 关注指标横滑（FR-SEM-07）；每张卡：指标名 + 当前值 + 同环比（颜色箭头）+ 迷你趋势；点击卡片下钻指标详情；hover 上浮 |
| 统计卡趋势切换 | 「生产运营趋势」卡右上分段器（近7日 / 近30日 / 近12月），点击切换数据并重绘图表，200ms 内反馈激活态 |
| 快捷入口宫格 | 图标 + 文字六入口，点击直达对应创建页（PRD 5.3） |
| 常用看板卡片流 | 缩略图 + 名称 + 最近访问时间 + 收藏星标；支持「最近 / 最热 / 收藏」排序切换；星标点击即收藏 / 取消，Toast 反馈 |
| 待办与消息 | 待办审批 / 告警 / 系统通知三类图标区分；点击直达对应页面上下文；告警条目带 `--danger` 标记与「查看归因」链接 |
| 首页布局管理 | 卡片可拖拽调序、可显隐（FR-HOME-19~22）；「恢复默认」需二次确认；布局保存后 Toast「布局已保存」 |

### 4.2 指标中心（IX-PAGE-02）

| 区域 | 交互细则 |
| --- | --- |
| 指标目录树 | 左侧树按主题域 / 部门组织（石油 / 天然气 / 化工 / 煤矿为一级主题域，配行业标记 `.ind`）；可展开折叠；选中节点高亮并过滤右侧列表；顶部搜索框即时过滤树节点 |
| 顶部操作栏 | 「新建指标」`.btn.primary` + 搜索 + 筛选（认证状态 / 负责人 / 创建时间）+ 视图切换（列表 / 卡片分段器） |
| 指标列表 | 行 = 指标名 + 类型标签（原子 `--info` / 派生 `--chem`）+ 认证标记（已认证 `--ok` 盾标）+ 负责人 + 热度 + 行内操作（查看 / 编辑 / 删除）；行 hover 显示操作；删除需二次确认 |
| 指标卡片视图 | 卡片 = 指标名 + 当前值（`--font-num`）+ 迷你趋势 + 口径摘要（ellipsis 两行）；点击进详情 |
| 指标详情抽屉 | 右侧 460px `.drawer` 滑入；Tab：概览 / 口径定义 / 血缘 / 版本历史 / 认证记录 / 评论（PRD 5.3 页面2）；血缘 Tab 内为可缩放关系图；Esc 关闭 |
| 指标定义向导 | 五步：① 选择数据集 → ② 定义维度 / 度量 → ③ 指标属性（名称 / 口径 / 归属）→ ④ 预览验证 → ⑤ 保存发布；每步可返回；步骤条当前步 `--brand`，已完成 `--ok`；预览数据为空时允许保存但标「无数据」标记（UC-001 备选流程 5a） |
| 关注按钮 | 星标关注后该指标进入首页指标卡区；取消关注 Toast 给 5 秒撤销（IX-FB-07） |
| 认证操作 | 管理员点「认证」填认证说明 → 指标全局显示「已认证」绿色标记并搜索优先（FR-SEM-05 / US-016）；撤销认证需二次确认 |

### 4.3 智能问数 ChatBI（IX-PAGE-03）

| 区域 | 交互细则 |
| --- | --- |
| 对话区 | 用户气泡右对齐（`--brand-soft` 底）、系统回答左对齐（玻璃卡）；回答 = 图表 + 数据表格 + 自然语言结论三段式 + 取数逻辑折叠区（UC-002） |
| 输入框 | 底部固定；Enter 发送、Shift+Enter 换行；左侧 `+` 上传文件 / 选择指标；输入时联想推荐（术语 / 指标 / golden queries）；未配置 LLM 时整个模块入口隐藏（NFR-AI-02） |
| 取数逻辑 | 「查看取数逻辑」折叠展开：指标、维度、筛选、时间范围、SQL（可选展示）；提供「一键转图表」「复制 SQL」（FR-AI-03，NFR-AI-03） |
| 流式响应 | 回答流式渲染：先骨架 → 结论逐字 → 图表最后；总耗时 ≤5s（NFR-PERF-07）；期间输入框转「停止生成」按钮 |
| 澄清交互 | 歧义时系统追问 + 可点击选项按钮（如「时间范围：[本月] [上月] [本季度]」），点击即答无需打字（US-009） |
| 上下文条 | 顶部「当前上下文：原油产量 · 2026年8月」，点击 ✕ 清除重开；追问引用前文 ≥5 轮（UC-002 验收 5） |
| 历史记录 | 左侧「我的问数」按时间分组，点击恢复对话；单条可删（二次确认） |
| 推荐问题 | 输入为空时展示推荐问题（热门 + 按角色），点击直接提问 |
| 反馈按钮 | 每条回答下「有用 / 无用」；无用弹出原因表单（答非所问 / 数据不对 / 图表不合适 / 其他），写入问数日志用于准确率评估 |
| 转存操作 | 回答右上「转图表 / 添加到看板 / 分享」；添加到看板弹看板选择器（可新建）；分享生成链接并 Toast 复制 |

### 4.5 系统管理 - 权限配置（IX-PAGE-05）

| 区域 | 交互细则 |

| 列级权限配置 | 选资源 + 角色 → 字段勾选表；敏感字段自动标红锁图标（FR-AUTH-11 / FR-GOV-14） |
| 脱敏规则配置 | 选字段 + 角色 + 方式（掩码 / 截断 / 替换 / 哈希）+ 参数（如保留前 3 后 4）；「测试效果」实时预览脱敏结果（FR-GOV-15/16） |
| 审计日志 | 列表按时间 / 用户 / 操作类型筛选；关键操作（权限变更 / 数据导出 / 登录失败）`--warn` 高亮；可导出（导出走二次确认 + 外发审计 NFR-SEC-11） |

### 4.6 数据源向导（扩展，IX-PAGE-06）

三步向导：① 选类型（数据库 / 文件 / HTTP / 实时流，图标宫格）→ ② 填连接（JDBC URL / 用户 / 密码 / 驱动，密码框可显隐切换）→ ③ 测试连接并保存。「测试连接」按钮点击即 loading，3 秒内返回结果（FR-DS-03）：成功 `--ok` 对勾 + 「连接成功 · 延迟 86ms」，失败 `--danger` + 原因 + 排查建议。保存前未测连接时给提醒但不强制阻断。

### 4.7 数据集查询构建器（扩展，IX-PAGE-07）

选表（左树搜索）→ 拖字段 → 过滤条件行（字段 + 操作符 + 值）→ 聚合分组 → 排序；每步右侧实时预览前 100 行（FR-PREP-01）；「SQL 逃生舱」切换为 CodeMirror 编辑 `${param}` / `${pc(param)}` 语法高亮，切回可视化时若 SQL 不可解析则保留 SQL 态并提示；预览失败给行列级错误定位。

### 4.8 告警规则三步配置（扩展，IX-PAGE-08）

① 选指标（带行业标记与当前值预览）→ ② 阈值条件（高于 / 低于 / 变化率超过 X%，可配持续 N 周期）+ 检测频率（cron 可视化生成器）→ ③ 通知渠道（邮件 / Webhook / 站内信 / 企微 / 飞书多选）+ 接收人 + 静默期（如 22:00-8:00）+ 去重（24h 内同类一次）（UC-004）；保存后展示下次检测时间；指标无数据时阻止保存并提示（UC-004 异常 2a）。

### 4.9 看板列表（扩展，IX-PAGE-09）

卡片流（缩略图 + 名称 + 行业标记 + 更新时间 + 热度）与表格双视图；排序：最近 / 最热 / 收藏；右键菜单：编辑 / 分享 / 复制 / 删除 / 导出；分享弹窗给「链接 / 密码 / 签名 Token 嵌入」三选项卡（FR-EXCH-08~10 / FR-EMBED-01）；空态给「新建看板 + 套用行业模板」双任务入口（IX-FB-03）。

### 4.10 数据大屏（扩展，IX-PAGE-10）

大屏页为 `data-no-shell` 全屏播放态：进入默认全屏（浏览器允许时），Esc 退出；鼠标静止 3 秒隐藏光标与控件；底部悬停呼出播放控制条（上一页 / 下一页 / 轮播开关 / 刷新间隔 / 退出）；轮播切换 ≤500ms（PRD 6.4）；告警滚动条点击某条暂停滚动并弹详情；断线时右上角 `--danger` 重连提示，恢复后自动续播。

## 6 移动端交互

### 6.1 手势对照表（IX-MOB-01，对齐 PRD 6.5）

| 手势 | 场景 | 系统响应 | 反馈时限 |
| --- | --- | --- | --- |
| 点按 | 指标卡 / 看板卡 / 列表行 | 打开详情 / 下钻一级 | ≤300ms（PRD 6.4 触控口径） |
| 双指缩放 | 图表 / 地图 | 缩放数据窗口或视图；松手吸附到合理刻度 | 跟手 |
| 左右滑动 | 看板多页 / 指标卡横滑区 | 翻页，带页点指示器 | 跟手 + 吸附 |
| 长按 | 图表数据点 / 列表项 | 显示详情浮层（十字指示 + tooltip）/ 呼出操作菜单 | 500ms 触发 |
| 下拉刷新 | 看板 / 消息列表 | 刷新数据，顶部菊花 + 「更新于 HH:mm」 | 下拉 ≥60px 触发 |
| 上拉加载 | 历史列表 / 告警历史 | 加载下一页（每页 20 条） | 触底自动 |

### 6.2 分享与推送深链（IX-MOB-02）

一键分享到微信 / 企微 / 钉钉 / 短信 / 邮件，生成分享卡片（标题 + 缩略图 + 二维码）；推送通知（告警 / 订阅 / 系统消息）点击深链直达具体看板或告警详情（PRD 6.5 / S-01）；无权限打开时提示「您暂无权限查看」并提供申请入口（对齐用户旅程 1 断点 5）。

### 6.3 离线缓存提示（IX-MOB-03）

常用看板离线缓存；弱网打开缓存数据时顶部横幅「离线数据 · 更新于 2026-09-03 06:30」（`--warn` 系），联网后自动刷新并撤横幅；缓存超过 24h 未更新时横幅升 `--danger`。

### 6.4 动态水印（IX-MOB-04）

看板 / 报表页全屏铺动态水印（用户名 + 工号 + 当前时间，45° 平铺，`rgba(255,255,255,.05)` 不遮挡数据）；截屏防护提示（FR-MOB-33~41）；水印不可通过前端手段关闭。
