# 不迁移清单（冻结面）

> 与迁移清单同等重要：保护对外嵌入契约与用户存量数据，改造期**零改动**。
> 依据：《前端Vue化前后端分离改造方案-v2》§3、§6.11；代码核查 `SecurityConfigSupport`、6 个视觉运行时控制器、`datagear-analysis` freemarker 用途。

---

## 一、对外嵌入契约（URL 层）

| 对象 | URL 模式 | 控制器 | 说明 |
|---|---|---|---|
| 图表展示 | `/cv/**` | `ChartVisualController` | 图表 iframe 嵌入运行时 |
| 看板展示 | `/dv/**` | `DashboardVisualController` | 看板 iframe 嵌入运行时 |
| 图表 5.0 兼容 | `/chart/show/**`、`/chart/showData*`、`/chart/heartbeat*`、`/chart/unload*` | `ChartVisualCompatController` | 5.0.0 公开 URL |
| 看板 5.0 兼容 | `/dashboard/show/**`、`/dashboard/showData*`、`/dashboard/loadChart*`、`/dashboard/auth/**`、`/dashboard/authcheck/**`、`/dashboard/heartbeat*`、`/dashboard/unload*` | `DashboardVisualCompatController` | 5.0.0 公开 URL |
| 2.6 兼容 | `/analysis/chart/show/**`、`/analysis/dashboard/show/**` | `CompatibleController` | 2.6.0 公开 URL |
| 插件运行时资源 | `/vres/plugin/**`（含 `chartPluginManager.js`） | `ChartPluginVisualResController` | 150 个 zip 插件运行时 + manager JS |

> 这些端点本就不走 FreeMarker 视图，是下游 iframe 嵌入 / 老版本 URL 兼容契约，**不可破坏**。SPA 化后继续由后端托管。

## 二、认证 / 安全机制（冻结）

| 机制 | 位置 | 处置 |
|---|---|---|
| 校验码端点 `/checkCode/**` | `CheckCodeController` + `CheckCodeManager` | 冻结，Session 存储，登录必需 |
| 表单登录 `/login/doLogin`、`/logout` | `SecurityConfigSupport` + `FormLoginConfgBean` | 阶段一 Session 同源方案不动 |
| 匿名用户数据库默认角色装配 | `AnonymousAuthenticationFilterExt` | 冻结（看板匿名权限语义依赖它） |
| `;jsessionid=` URL 会话 | `StrictHttpFirewall.setAllowSemicolon(true)` | 冻结（iframe 嵌入 + 第三方 Cookie 禁用兜底） |
| CSRF 禁用 | `http.csrf().disable()` | 维持（阶段一不变） |
| frameOptions 禁用 | `http.headers().frameOptions().disable()` | **维持禁用**（iframes 嵌入需要） |
| 登录锁定（IP + 用户名双闸） | `ipLoginLatch` / `usernameLoginLatch` | 冻结 |
| remember-me（365 天） | 表单登录配置 | 冻结 |

## 四、数据集模板语言（freemarker 数据功能依赖，保留）

| 对象 | 位置 | 处置 |
|---|---|---|
| freemarker jar 依赖 | `datagear-analysis/pom.xml` | **保留** |
| `analysis/support/datasettpl/` 包 | `DataSetFmkTemplateResolver`、`SqlDataSetFmkTemplateResolver`、各 OutputFormat | **保留**，定位为"数据集模板引擎" |
| 用户存量数据集内的 freemarker 语法 | 数据库 | 不触碰（兼容 = 重写一个 freemarker，不可行） |

> 同步隔离工作：(a) 在 `datasettpl` 包抽象 `TemplateResolver` SPI（接口已存在，补齐默认实现装配隔离）；(b) 文档明确"FreeMarker 是数据集模板语法，与视图层无关"。

7. 图表插件运行时 JS 注入与展示
8. 心跳轮询 `/dv/heartbeat` 不报错
