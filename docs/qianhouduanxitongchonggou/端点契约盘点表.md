# 端点契约盘点表（阶段零 · 交付物）

> 生成方式：脚本 + 人工核查 32 个 `@Controller`（`org.datagear.web.controller` 包）与 `SecurityConfigSupport` 权限矩阵。
> 核查基准：`datagear-web/src/main/java/org/datagear/web/controller/`、`datagear-web/.../config/SecurityConfigSupport.java`、`web/util/OperationMessage.java`、`datagear-util/.../query/PagingData.java`。
> 状态：✅ 与代码一致（32 个 `@Controller`，0 个 `@RestController`）。

---

## 一、总览

| 统计项 | 值 |
|---|---|
| `@Controller` 数量 | 32 |
| `@RestController` 数量 | 0（全部走 `@Controller` + 方法级注解/`@ResponseBody`） |
| 端点映射总数（方法级 `@RequestMapping`） | ~230 |
| 返回形态 | 4 类（视图 / JSON 包装 / 裸 JSON / 流式） |
| 权限级别 | 6 级（admin / dataManager / dataAnalyst / user / anonymous / access） |

---

## 二、返回形态分类（迁移分类的依据）

| 代号 | 判定 | 现状示例 | 迁移决议 |
|---|---|---|---|
| **视图** | `public String xxx(...)` 返回 FreeMarker 视图名（无 `@ResponseBody`、无 `produces=JSON`） | `/role/add`、`/role/manage`、`/dashboard/design/{id}` | 转为 SPA 路由页面（范式 A/B/C），后端端点整体删除 |
| **JSON包** | `ResponseEntity<OperationMessage>` | `/role/saveAdd`、`/role/delete` | 保留，`/api` 前缀化 + `OperationMessage<T>` 泛型化 |
| **裸JSON** | `@ResponseBody` + 原始类型（`PagingData<T>`/`List<T>`/`Map`/`boolean[]`/实体） | `/role/pagingQueryData`（PagingData）、`/authorization/{resourceType}/{resource}/queryData`（List） | **阶段二统一**：包进 `OperationMessage<T>`（见 §五 决议清单） |
| **流式** | `void` 直接写 `response`（下载/导出/资源/图标/日志流） | `/chartPlugin/download`、`/dataSet/downloadFile`、`/dtbsSourceExchange/{id}/export/download` | 保留（下载类不 JSON 化，走 blob） |
| **HTML片** | `produces = CONTENT_TYPE_HTML` | `/dataSet/resolveSql` | 决议：改 JSON 或冻结（见 §五） |

> 关键事实：现有 `@RequestMapping` 绝大多数**未显式限定 HTTP 方法**（接受 GET/POST/PUT/DELETE 等），`/api` 化时需逐端点明确方法，避免契约漂移。

## 三、权限级别（来自 `SecurityConfigSupport` / `AuthenticationSecurity`）

| 代号 | 判定方法 | 语义 |
|---|---|---|
| admin | `hasAdmin` | 系统管理员 |
| dataManager | `hasDataManager` | 数据管理员 |
| dataAnalyst | `hasDataAnalyst` | 数据分析员 |
| user | `hasUser` | 已登录用户 |
| anonymous | `hasAnonymous` | 匿名（含数据库装配的默认角色） |
| access | `hasAccess` | 任意访问（认证/匿名均可） |

## 七、结论

- 端点体量与形态与方案一致：**视图端点（String 返回）与 JSON 端点（JSON包 + 裸JSON）约为 45% : 55%**。
- 已识别裸返回端点 10 处、HTML 片段 2 处、流式豁免端点 6 组，均已列入 §五 决议清单。
- 权限矩阵 6 级、Session 依赖 10 项、冻结面 6 个控制器，均已定位，可直接驱动阶段二后端 API 化与阶段三/四前端迁移。
