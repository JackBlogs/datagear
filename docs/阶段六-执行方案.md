# 阶段六：执行方案（脱离 FreeMarker 落地清单）

> 状态：SPA 已 Vue 化绝大部分视图（列表 + CRUD 表单 + 设计器 + 复杂模块 + iframe 脱离），
> 本方案给出「删除 FreeMarker 视图体系」前的剩余前置项与 Java 层清理步骤。

---

## 一、剩余 Vue 化清单（按优先级）

| 模块 | 说明 | 复杂度 | 状态 |
|---|---|---|---|
| driverEntity | 驱动管理（增删改 + jar 上传） | 中 | 元数据 CRUD 已 Vue 化；**jar 上传未做**（走旧 `/driverEntity/uploadDriverFile`） |
| authorization | 资源授权（用户/角色 × 资源 × 权限） | 高 | 未做 |
| dtbsSourceData | 数据管理（表数据 CRUD，动态列） | 高 | 未做 |
| dtbsSourceUrlBuilder | URL 构建器工具 | 中 | 未做 |
| chartPlugin | 图表插件管理（上传/查看/手动） | 高 | 未做 |
| dashboard 分享/导入 | 看板密码分享、导入 | 中 | 未做 |
| 公共页 | register / resetPassword / about / changelog | 低 | 未做（login 已 Vue） |
| user/role view 只读页 + 密码修改 | 查看详情、改密码 | 低 | 未做 |

> 说明：未 Vue 化的模块，其**旧 JSON 端点**（saveAdd/saveEdit/delete 等 `produces=JSON`）在删除
> FreeMarker 后仍可用；只有**旧 GET 视图端点**（返回 `"/xxx/xxx_form"` 等 .ftl 视图名）会失效。
> 因此删除前需确保 SPA 不调用任何旧 GET 视图端点。

---

## 二、Java 层 FreeMarker 清理（删除前必做，否则编译失败）

### 1. `AbstractController.java`
- 删除 `import freemarker.template.TemplateModel;`
- 删除 `import org.datagear.web.freemarker.WriteJsonTemplateDirectiveModel;`
- 删除/改造成员方法：
  - `toWriteJsonTemplateModel(Object)` / `fromWriteJsonTemplateModel(Object)`
  - `setFormModel(Model, Object)` / `getFormModel(Model)`（仅旧视图用）
- `setErrorAttrIfIsJsonResponse` 中 `request.setAttribute(KEY_OPERATION_MESSAGE, toWriteJsonTemplateModel(operationMessage))`
  改为 `request.setAttribute(KEY_OPERATION_MESSAGE, operationMessage)`（或删除该行）。

### 2. `WebMvcConfigurerConfigSupport.java`
- 删除 FreeMarker 视图解析器注册：`createFreeMarkerViewResolver` / `configFreeMarkerViewResolver` /
  `freeMarkerViewClass` / `createFreeMarkerConfigurer` / `getFreeMarkerTemplateLoaderPaths`。
- 删除 `import CustomFreeMarkerView / WriteJsonTemplateDirectiveModel / FreeMarkerConfigurer /
  FreeMarkerView / FreeMarkerViewResolver`。
- `registry.viewResolver(viewResolver)` 那一段整段移除。
- 若 SPA 完全独立，可删除 `errorPageRegistrar`（错误页指向 `/error`），改为 JSON 错误响应。

### 3. 错误处理
- `error.ftl` 删除后，异常兜底需走 `DeliverContentTypeExceptionHandlerExceptionResolver`（JSON）。
- 401 已由 `AjaxAwareAuthenticationEntryPoint` 对 `X-Requested-With` 返回 JSON。

### 4. `spring-boot-starter-freemarker` 依赖
- 从 `datagear-webapp/pom.xml` 移除。

## 四、收敛执行顺序（建议）
1. 完成「一」中剩余 Vue 化（至少 authorization、公共页、dashboard 分享）。
2. 执行「二」Java 清理 + `mvn clean install` 通过。
3. `git mv` 136 个 .ftl → `deprecated/templates`（可回滚）。
4. `scripts/converge-phase6.sh --execute`（当前脚本会 git mv 模板/四件套/lib）。
5. 前端 `npm run build` 产物拷入静态资源目录。
6. M5 冒烟：iframe 嵌入、密码分享、匿名访问、Compat 控制器、双形态打包。

---

## 五、风险与回滚
- 删除前务必 `git mv` 到 `deprecated/`，保留一个迭代。
- 若某旧 GET 视图端点仍被外部书签引用，SPA 路由 `NotFoundView` 兜底。
- `;jsessionid=` URL 兼容、`frameOptions` 禁用需保持（见冻结面）。
