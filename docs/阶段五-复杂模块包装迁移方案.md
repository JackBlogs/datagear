# 阶段五：复杂模块包装迁移方案（骨架）

> 目标：在不重写的前提下，把三个最重的模块（数据交换 / SQL 工作台 / 看板设计器）迁入 SPA。
> 依据：《方案》§6.10。原则：**包装迁移优先，逐步重写**。

---

## 一、三个复杂模块的体量事实（已核查）

| 模块 | 体量 | 关键机制 |
|---|---|---|
| 5a 数据交换 + URL 构建器 | 11+11 模板 + 11 include；列映射 importKeys、子任务 start/suspend/resume/stop、进度存 Session、Zip 流式下载 | `DtbsSourceExchangeController` / `DtbsSourceUrlBuilderController` |
| 5b SQL 工作台 sqlpad + dtbsSourceData | 单 ftl 1316 行；编辑器 + 服务端补全 + 执行 + 结果网格 + 历史；库表在线增删改、LOB/二进制、HEX | `DtbsSourceSqlpadController` / `DtbsSourceDataController` / `DtbsSourceSqlEditorController` |
| 5c 看板设计器 | ftl ~3600 行（属性面板单文件 2984 行）+ dashboardDesign.js 120KB/437 函数；iframe 内就地支取编辑、拖拽插入 | `DashboardController.design()` + visual-editor-iframe 机制 |

---

## 二、统一前置：后端把 Session 进度改 JSON 轮询

数据交换的批任务进度目前存在 Session（见《端点契约盘点表》§六 #6）。包装迁移前，先配合后端：

1. 新增 `GET /api/dtbsSourceExchange/{id}/progress` 轮询接口（替代 Session 进度）；
2. `getLogContent`（HTML 片段）改 JSON 日志接口；
3. `uploadImportFile`（裸 List）改 `OperationMessage<List<...>>` 包装。

---

## 三、5a 数据交换 + URL 构建器（范式 C 向导页）

```
/api/dtbsSourceExchange/{id}/import/{csv|sql|json|excel}  → 向导页（useSteps）
/api/dtbsSourceUrlBuilder/set                              → URL 可视化构建页
```

- 复用组合函数：`useSteps()`（步条）、`useImportKeys()`（列映射）、`useFileUpload()`。
- 组件化：导入向导 4 类型（csv/sql/json/excel）拆为 4 个步骤组件，导出同理。

## 四、5b SQL 工作台（范式 C）

```
/api/dtbsSourceSqlpad/{id}  → SQL 工作台页（useSqlEditor）
```

- `useSqlEditor()`（P2）先行：CodeMirror 5 锁定 + 服务端补全（`/api/dtbsSourceSqlEditor/{id}/findTableNames|findColumns`）。
- 结果网格复用 `usePagingTable` 变体（分页/排序）；LOB/二进制列、HEX 工具作为列渲染器组件。

## 五、5c 看板设计器（两步走，不做一次性重写）

**第一步：包装迁移（外壳 SPA 化）**
- 设计器外壳用 SPA 路由页 + KeepAlive；iframe 内编辑原样复用 `dashboardDesign.js`（保持 visual-editor-iframe 机制）；
- 即：`/api/dashboard/{id}/design` 外壳页内嵌 iframe，iframe 加载旧 `/dashboard/design/{id}` 视图（双轨期保留旧视图）。

**第二步：属性面板分步重写（视收益）**
- 属性面板单文件 2984 行 → 按属性分组（图表类型/数据/样式/交互）拆为 Vue 组件，逐组替换；
- 拖拽插入图表 → 用 Vue 拖拽库 + 后端 `/api/dashboard/design` 资源接口逐步替代。

---

## 六、验收要点

- 5a：导入/导出各类型逐项回归；子任务启停；进度轮询；Zip 流式下载。
- 5b：SQL 执行/补全/历史/结果网格/库表增删改/LOB 列。
- 5c：iframe 内编辑不回归（重点）、拖拽插入图表、属性面板保存。
